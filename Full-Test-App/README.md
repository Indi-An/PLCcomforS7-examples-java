# Full-Test-App – PLCcom Feature Test Application (Java)

This project is a Java test application that bundles many PLCcom features in one place.
It is intended for evaluation, troubleshooting and quick experiments.

Typical modules (depending on implementation):
- Connect/Disconnect
- Reads/Writes
- Subscriptions
- Browsing address space
- Alarms
- Diagnostics/logging

Notes:
- This is a test/demo tool, not a production runtime.
- For focused minimal samples, see Symbolic-Access/ and Put-Get-Access/.
