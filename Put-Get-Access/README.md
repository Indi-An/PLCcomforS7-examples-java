# PUT/GET Access – Examples (Java)

This folder contains examples for classic PUT/GET access.
Each subfolder is a standalone sample project.

Start with 01 and continue in order.

## Projects
- 01_simple_read_example (all licenses)
- 02_simple_write_example (all licenses)
- 03_optimized_reading_and_writing (Expert feature; AUTO optimization is Expert-only)
- 04_simple_dataserver (Expert feature)

## Notes
PUT/GET may be restricted by PLC security/protection settings.
Verify permissions if read/write fails.
